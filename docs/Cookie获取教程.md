# Cookie 获取教程（BAIDUWP_COOKIE）

脚本需要的 cookie 由两个值组成：**BDUSS**（必需）和 **STOKEN**（任务中心签到/补签需要，建议一起拿）。两者都只能通过**已登录的浏览器**获取，下面是最简单的电脑浏览器方法。

---

## 方法一：电脑浏览器 F12（推荐，2 分钟搞定）

以 Chrome / Edge 为例（其他 Chromium 内核浏览器相同）：

1. 打开 [pan.baidu.com](https://pan.baidu.com)，正常登录你的百度账号（扫码/账密均可）

2. 按 **F12** 打开开发者工具，点击顶部标签栏的 **「Application」**（中文版叫「应用程序」；Mac Safari 用户建议换 Chrome）

   > 如果看不到 Application 标签，点开发者工具右上角 `»` 展开更多标签

3. 左侧栏找到 **「Storage → Cookies」** 并展开，点击 **`https://pan.baidu.com`**

   > ⚠️ 必须在 Application 面板里看。这两个值都是 HttpOnly 属性，在 Console 里输 `document.cookie` 是**看不到**的

4. 在右侧 Cookie 表格中分别找到两行，**双击 Value 列**全选复制：

   | Name | 长度参考 |
   |---|---|
   | `BDUSS` | 约 192 位的长串 |
   | `STOKEN` | 64 位 |

   双击后会进入编辑态，`Ctrl+A` 全选 → `Ctrl+C` 复制，确保一个字符不少。

5. 拼成环境变量的值（注意格式）：

   ```
   BDUSS=刚才复制的BDUSS值; STOKEN=刚才复制的STOKEN值
   ```

   - `BDUSS=` 和值之间无空格，两个值之间用 **分号+空格** 分隔
   - 不要加引号、不要换行、不要带上表格里的其他列

6. 粘贴到青龙 **环境变量 → 新建变量**：
   - 名称：`BAIDUWP_COOKIE`
   - 值：上面拼好的整串

完成。手动运行一次「百度网盘多合一签到」任务验证输出即可。

---

## 方法二：Network 面板整串提取（备选）

如果 Application 面板不好找，也可以从网络请求里直接拿整串 cookie：

1. F12 → **Network**（网络）标签 → 刷新 pan.baidu.com 页面
2. 点击列表中任意一个发往 `pan.baidu.com` 的请求 → **Headers**（标头）→ 找到 **Request Headers → Cookie**
3. 右键复制整串值，直接填入环境变量也可用（脚本会自动使用其中的 BDUSS/STOKEN，多余字段无害）

> 此方法会带上十几个无关 cookie（BAIDUID 等），不影响运行，只是长一些。

## 多账号

1. 普通（非无痕）窗口登录大号 → 按方法一取第一份
2. 开一个**无痕/InPrivate 窗口**登录小号（不影响普通窗口的登录态）→ 取第二份
3. 多份 cookie 用 **`&`** 或 **换行** 分隔，填在同一个 `BAIDUWP_COOKIE` 变量里：

   ```
   BDUSS=大号的; STOKEN=大号的&BDUSS=小号的; STOKEN=小号的
   ```

脚本会逐账号执行并在推送里分账号汇报。

## Cookie 什么时候会失效

| 值 | 有效期 | 失效后表现 |
|---|---|---|
| `BDUSS` | 很长（年级），**修改密码/账号退出登录**会立即作废 | 推送"BDUSS 已失效"，全部功能不可用 → 重新获取整串 cookie |
| `STOKEN` | 中等，但**随正常使用自动滑动续期** | 推送"任务中心签到失败: STOKEN 已失效"，此时**其余功能全部正常** → 只需重新取 STOKEN 更新变量 |

日常使用中只要浏览器/手机 App 还在正常登录使用网盘，STOKEN 基本不会失效。

## 常见问题

**Q: 报"BDUSS 已失效"，但刚取的？**
检查是否复制完整（BDUSS 很长容易被截断）、是否误删了 `BDUSS=` 前缀、账号是否在别处退出了登录。

**Q: 报"任务中心签到失败: invalid bduss"？**
这是缺 STOKEN（或 STOKEN 失效）的报错，补上 `STOKEN=...;` 即可。

**Q: 手机上能取吗？**
手机浏览器没有开发者工具，不方便。建议用电脑操作一次（1 分钟）；实在没有电脑，可用支持抓包的工具取 Cookie 请求头，但不推荐。

**Q: 安全性？**
BDUSS 等同于账号的登录凭证（拿到即可免密登录）。它只需要填在**你自己青龙面板的环境变量里**，不要发给任何人、不要截图外传、不要提交到任何仓库或 issue。
